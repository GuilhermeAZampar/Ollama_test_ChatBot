# Ollama Memory Chatbot 🤖

Chatbot local desenvolvido em Python utilizando Ollama e Llama 3.2, criado como projeto de estudo sobre LLMs e sistemas de memória.

## Funcionalidades

- Chat local com Llama 3.2
- Histórico e gerenciamento de contexto
- Memória persistente em JSON
- Classificação automática de informações
- Criação, atualização e recuperação de memórias
- Structured Outputs com JSON Schema
- Streaming das respostas

## Tecnologias

- Python
- Ollama
- Llama 3.2
- JSON

## Objetivo

Projeto desenvolvido para estudar na prática o funcionamento de LLMs, contexto, memória persistente e integração de modelos locais com Python.
